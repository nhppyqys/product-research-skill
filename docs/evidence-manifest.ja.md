# エビデンス・マニフェスト

[English](evidence-manifest.md) · [简体中文](evidence-manifest.zh-CN.md) · **日本語**

完了基準の中には、出来上がったレポートからは読み取れないものがあります。いくつのパスを叩いたか、いくつの事例を読んだか、ベンダーの動画チャンネルを見たか——**これらは成果物ではなく調査プロセスを記述するもの**で、宣言できるのは調査した本人だけです。

そこで、同名の兄弟ファイル `<report>.evidence.json` に置き、**レポートには決して同梱しません**。チェッカーが自動的に拾います。

```json
{
  "shape": "セルフサーブ SaaS",

  "pathSpace": [
    "sitemap.xml：223 URL",
    "robots.txt：Disallow 7 件、sitemap 宣言 8 件",
    "llms.txt：404（ただしペイロードに JSON-LD あり）"
  ],

  "probedPaths": ["/pricing 200", "/docs 200", "/security 404", "..."],
  "openedIndexPages": ["/pricing（レンダリング後、全プランを操作）", "/limits", "/errors"],
  "caseStudiesRead": ["acme-corp 2026-05", "globex 2026-03", "initech 2025-11"],
  "peerPricingPages": ["a.com/pricing", "b.com/pricing", "c.com/pricing"],
  "videoChannelChecked": "youtube.com/@vendor —— タイトル 25 件を確認、2 件をフレーム抽出用に取得",

  "skipped": {
    "case-studies": { "reason": "absent", "note": "サイトに事例ページが無い" }
  }
}
```

## 形態専用ステップは `shape` で発火する

契約には特定の形態にのみ適用されるステップが 3 つあります——オープンソースのライセンス分解、マーケットプレイスの供給側と需要側。**これらはこのフィールドで発火し、レポート本文から推測されることは決してありません。**

⚠️ 以前のバージョンはレポート本文をキーワードで照合して形態を推測していました。**「市場」というありふれた語が、通常の SaaS レポートでマーケットプレイス専用ステップを発火させました。****誤検知のコストは偽アラームであり、偽アラームは人にアラームを無視することを教えます。**

`shape` が未宣言の場合、これらのステップはスキップされ、チェッカーが末尾で通知します。

## ステップを飛ばす

理由は 3 つだけ。それ以外は未達成として記録されます。

| `reason` | 意味 |
|---|---|
| `blocked` | フォールバック経路を全て試して失敗。**どれを試し、それぞれ何が返ったかを明記。** |
| `absent` | 対象が本当に存在しない——モバイルアプリが無ければアプリストアのレビューも無い |
| `incapable` | 環境が本当にできない。**実際に試した上で、コマンドとエラー文を引用すること。** |

⚠️ `incapable` に但し書きが付いている理由：**5 ラウンド連続で乱用された**からです——スクリーンショット欄が毎回空で、理由はいつも「環境にレンダリング能力が無い」、**しかし一度も試されていませんでした**。6 ラウンド目に試したところ、すぐに動きました。

**「気力が尽きた」「予算超過」は理由になりません。**予算が本当に足りないなら範囲を狭めてください——競合を 1 社減らす——**すべての項目を中途半端にやるのではなく**。

## 実行方法

```bash
node scripts/check-report.mjs report.md                      # report.evidence.json を自動で拾う
node scripts/check-report.mjs report.md --manifest other.json
```

各ステップは 4 状態：

```
✓ 達成        ✗ 未達成        ? 未宣言        ⊘ 免除
```

未達成の項目、または衛生面の必須エラーがある場合、終了コードは 1 です。
